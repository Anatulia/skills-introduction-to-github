# Marp

Ecosystem to write presentations in **plain Markdown** — used in the
[[llm-wiki-pattern]] to generate slide decks straight from wiki pages.

- **Repo:** github.com/marp-team/marp · Site: marp.app

## Key facts
- **Components:** Marpit (MD→slides framework), Marp Core (themes/features),
  Marp CLI (export to HTML/PDF/**PPTX**/images), Marp for VS Code (live preview).
- **Role in the brain:** turn a synthesis page into a deck on demand.
