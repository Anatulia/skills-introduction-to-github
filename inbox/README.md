# 📥 inbox — sbarco generico

Trascina qui (da github.com → **Add file → Upload files**) qualsiasi file che vuoi
farmi leggere o ingerire: PDF, testo, Word, immagini, note, screenshot.

Vedi la guida completa in `../UPLOAD-GUIDE.md`.

## Cosa faccio quando carichi qualcosa
1. Faccio `git pull` e leggo i file presenti qui.
2. Li smisto nel progetto giusto (es. `second-brain/sources/`) e creo/aggiorno le pagine.
3. Sposto i file processati in `_done/`.
4. Aggiorno gli indici e i log.

## Regole
- ⚠️ Niente video/audio pesanti (usa la trascrizione) né segreti/credenziali.
- Un file = un contenuto, con nome descrittivo.
